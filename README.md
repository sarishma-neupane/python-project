# Tic-Tac-Toe Game (Python)

A classic interactive **Tic-Tac-Toe** game built using Python. Two players can take turns playing the game directly inside the terminal window.

## Features
* Interactive two-player gameplay (Player X and Player O)
* Built-in win checking and tie game detection
* Real-time grid rendering directly in the terminal interface

## How to Run the Game

1. Make sure you have Python installed on your computer.
2. Download the `tic_tac_toe.py` file from this repository.
3. Open your command prompt, terminal, or VS Code.
4. Run the script using the following command:
   ```bash
   python tic_tac_toe.py
   ```
5. Enter grid coordinates when prompted to take your turn!
